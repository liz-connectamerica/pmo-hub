PMO Hub is the team's project portfolio tool — request tracking, project management, and PMO reporting in one place.

Pick the guide that matches you:

- **[User Guide](user-guide/)** — for everyone. Browsing projects, submitting a request, tracking your own tasks and projects.
- **[Admin Guide](admin-guide/)** — for PMO Admins. Intake review, backlog prioritization, resourcing, capacity planning, and system administration.

If you're not sure which one you need, start with the User Guide — everything in it applies to admins too, since admins see everything a regular user sees plus more.
